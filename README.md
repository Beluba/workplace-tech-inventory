# Workplace Tech Inventory

A Python/Flask app for tracking computers, software licences, and networking equipment in a small office. Built to showcase workplace technology planning and procurement skills.

## Features
- Inventory of devices with serial numbers and purchase dates
- Software licence tracking with expiry alerts
- Network equipment register
- Export to CSV
- Simple SQLite backend

## Tech Stack
- Python 3.11+
- Flask
- SQLite
- HTML/CSS

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000
